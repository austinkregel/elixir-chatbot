Why this file exists
--------------------
The 2026-09-16 reference no longer reproduces, and that is expected: its
inputs changed. This is the reference later work compares against.

1. Entity data. data/entities and data/legacy were deleted on 2026-09-17.
   data/entities was recreated from the 2026-04-24 copy in
   data/training/entities: the 33 Dialogflow entry files plus room and
   ambiguous_name_location, renamed to underscores, contents byte-identical.
   The deleted data had diverged from that copy; measured against the
   previous gazetteer, it cost exactly two types, genre (88 words) and
   language (41). Nothing else it knew was lost.

2. Gazetteer. Rebuilt with no cap on artists or cities (18,190 artists and
   31,278 cities, previously 10,000 rows of each source), every candidate
   kept when sources share a word, and each record indexed once.

3. Entity types. Extraction returns system types (music_artist, sys_date),
   no longer relabelled to the NER gold standard's labels.

data/ and gazetteer.term are gitignored, so this commit does not by itself
pin the inputs above; the description here does.

Known limitations of these numbers
----------------------------------
- slot_completeness is measured against a generic fallback schema, not the
  intent registry. SlotDetector reads "priv/analysis/intent_registry.json"
  relative to the working directory (slot_detector.ex:8); run from the
  umbrella root the file is not found and a default schema is substituted
  silently. Every earlier reference has the same limitation.
- Which extraction path runs depends on timing: the ETS Gazetteer loads in a
  detached Task at boot (application.ex:97), and extraction uses the
  gazetteer.term path until it finishes. The two paths choose between
  candidates differently.

Stability
---------
Two consecutive runs at identical code produced identical values. The
certainty map in TEST 3 printed its keys in a different order between runs
(%{hedged: 360, committed: 90} vs %{committed: 90, hedged: 360}): small maps
print in atom-creation order, not sorted. Compare that line by value, not by
bytes.
