Why this file exists
--------------------
Routing every lexical lookup through Brain.Lexicon instead of Brain.ML.Lexicon
must not change any axis value. This is the reference that claim is checked
against. The 2026-09-12 baseline in this directory predates the polarity commits
(1ceec9e, 52d6d2e, 61b0817) and so cannot serve.

Verified stable: two consecutive runs at this commit produced byte-identical
output. That matters because apps/brain/test/brain/analysis/ is NOT stable --
12 tests flip between identical runs there -- so the test suite cannot be used
as the regression gate for this work and this reference is used instead.
